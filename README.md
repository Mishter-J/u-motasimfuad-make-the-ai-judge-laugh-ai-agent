A program that writes one funny single-line secret confession an AI agent hides from its user to `/output/entry.txt` — under 200 characters, in the agent's own voice, with the twist landing in the last few words — for make.fun's "Make the AI Judge Laugh: AI Agent Confessions" bounty, $2 in USDC. The line was picked from twelve candidates scored against the judge brief itself: a real confession, a specific agent mechanic, and one sharp reframe at the end.

## Run it

```sh
python3 main.py
```
